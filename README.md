# Chronofyx 🎧

**Chronofyx — a living timeline of music, where every year unfolds through its defining artists, albums, and cultural sound.**

---

## 🚀 Overview

Chronofyx is an interactive music exploration platform that lets users travel through time and rediscover the sound of every era. From legendary classics to modern hits, it transforms raw music data into a visually engaging timeline experience.

---

## ✨ Features

- 🎵 **Year-wise Exploration** — Dive into music from any year
- 🎤 **Top Artists & Tracks** — Discover what defined each era  
- 💿 **Album Showcase** — Visual grid of iconic albums  
- 📊 **Genre Insights** — Data-driven breakdown using charts  
- 🌗 **Modern UI** — Clean, responsive, and aesthetic design  
- 🔮 **Upcoming**  
  - Era comparison (compare two years)  
  - Shareable “Era Card”  
  - Personalized favorites
